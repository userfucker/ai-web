# AI Web

Chrome 插件：让 **DeepSeek、智谱清言、千问、Kimi** 的网页版（用免费额度）接入局域网中转站。

插件能做的事：
- 新建对话、发送、等待完成、读取回复。回复是从网站的流式接口解析的 Markdown，**思考过程会去掉**。
- 会话列表、批量删除、打开会话。
- 停止生成。

`relay-test/` 里有一个测试用的中转站，可以先用它在浏览器里同时指挥四个 AI。

## 安装插件（Chrome 116 以上）

1. 把 `extension` 文件夹放到一个固定位置。
2. 打开 `chrome://extensions`，打开“开发者模式”，点“加载已解压的扩展程序”，选 `extension` 文件夹。
3. 把插件钉到工具栏。点图标会出来弹出窗口，能看到连接状态和四个网站的状态。
4. 点“设置”，填中转站的**局域网 IP**、端口（默认 8765）、口令，点“保存并连接”。不确定能不能连上，可以先点“测试连接”。
5. 四个网站各登录一次。

升级：覆盖文件 → 扩展页点“刷新” → 刷新四个 AI 网页。

## 测试中转站

装好 [Node.js](https://nodejs.org)（18 以上），在中转站那台电脑上运行：

```
node relay-test/test-relay.mjs --port 8765 --token 你的口令
```

它会打印本机的局域网 IP。把这个 IP 填进插件设置，然后用浏览器打开 `http://那个IP:8765/`（手机也行）。控制页上可以：
- 同时给勾选的网站发问题，实时看回复；
- 每个网站单独“打开 / 新对话 / 停止 / 会话列表 / 删除选中 / 打开选中 / 切到窗口”。

Windows 第一次运行时防火墙会问要不要允许 Node 访问网络，选允许（专用网络）。其他电脑连不上的话，多半是防火墙没放行这个端口。

## 使用注意

- **每个网站单独开一个窗口，别最小化，也别放在同一个窗口的不同标签页里**，否则浏览器会限流后台页面。中转站让插件打开网站时，默认就是单独开窗口（可以在设置里改）。
- 电脑休眠、锁屏或者远程桌面断开，页面可能停止工作。
- 网页加载慢：插件会等输入框能用了再操作，最多等 60 秒。看到登录按钮、又没有输入框，会报“没登录”。2 分钟没收到任何回答文字，会报网站忙或被限流。
- 智谱清言的接口有签名，会话列表是读网站自己请求到的（必要时滚动侧边栏加载更多），删除是点界面一个一个删。同名会话分不清时不会删，结果里会写原因。
- 网站改版后可能失效。在网站上点插件弹出窗口里的“当前页调试面板”，用里面的采样功能下载报告，发给开发者修适配器。

## 调试面板（每个网站页面上）

弹出窗口 →“当前页调试面板”，可以：
- ① 识别元素 ② 测试输入方式 ③ 采样对话：网站改版后用来找原因；
- ④ 功能测试：一键测试，会话列表（勾选删除 / 打开），停止；
- ⑤ 会话列表采样 ⑥ 下载报告。

## 目录

```
extension/
  manifest.json   MV3
  background.js   连中转站（WebSocket、自动重连、心跳）、管理标签页、转发命令
  hook.js         网页主环境：拦截流式回复接口；记下网站自己的请求头，代发会话列表 / 删除请求
  sites.js        四个网站的适配器：选择器、写入方式、回复解析、会话列表 / 删除 / 打开
  content.js      执行命令；调试面板
  popup.*         工具栏弹出窗口
  options.*       设置（中转站 IP / 端口 / 口令 / 名字）
relay-test/
  test-relay.mjs  测试用中转站（不用装依赖）
docs/
  protocol.md     插件 ⇄ 中转站的协议（写正式中转站时看这个）
```
